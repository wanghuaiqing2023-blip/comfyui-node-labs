# B10 引导器与引导补丁

[项目首页](../../README.md) · [本阶段目录](README.md) · [全部实验](../README.md)

**前置能力**：[B07 拆开采样器](B07.md)。

**准备**：普通 CFG 基线；双模型或视频引导必须使用对应模板。

**操作与变量**：在其兼容基线上，每次只替换一种 guider 或加一种 guidance patch；比较关闭/中间/模板默认三档，固定其余输入。

**观察与通过标准**：区分条件、引导器和 MODEL 补丁；功能验证看配置被消费及可解释差异，质量结论至少三个固定种子。

**本组逐一验证的节点**：`CFGNorm`、`CFGZeroStar`、`LTXVModalityGuidance`、`LTXVSpatioTemporalGuidance`、`NAGuidance`、`SkipLayerGuidanceDiT`、`SkipLayerGuidanceDiTSimple`、`SkipLayerGuidanceSD3`、`TCFG`、`FreSca`、`PerpNeg`、`PerpNegGuider`、`Mahiro`、`SelfAttentionGuidance`、`APG`、`CFGOverride`、`DualCFGGuider`、`DualModelGuider`、`LTXVDualCFGGuider`、`VideoLinearCFGGuidance`、`VideoTriangleCFGGuidance`。

**初始状态**：待执行。一个节点的成功不能替同组其它节点验收。
