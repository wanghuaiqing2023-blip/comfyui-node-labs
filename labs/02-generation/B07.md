# B07 拆开采样器

[项目首页](../../README.md) · [本阶段目录](README.md) · [全部实验](../README.md)

**前置能力**：[B03 最小文生图与复现](B03.md)。

**准备**：匹配普通 CFG 的同一图像模型；使用确定性 sampler 起步。

**操作与变量**：RandomNoise、CFGGuider、KSamplerSelect、BasicScheduler 与 latent 接 SamplerCustomAdvanced；匹配 KSampler 的 seed/steps/scheduler/CFG/denoise；另测 SamplerCustom。

**观察与通过标准**：能分别指出 NOISE、GUIDER、SAMPLER、SIGMAS、LATENT 五个输入来源；输出接近基线，差异追查随机流与调度等设置。

**本组逐一验证的节点**：`SamplerCustom`、`SamplerCustomAdvanced`、`BasicGuider`、`CFGGuider`、`AddNoise`、`DisableNoise`、`RandomNoise`、`KSamplerSelect`、`BasicScheduler`。

**初始状态**：待执行。一个节点的成功不能替同组其它节点验收。
