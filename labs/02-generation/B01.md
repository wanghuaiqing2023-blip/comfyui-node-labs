# B01 加载器与最小条件编码

[项目首页](../../README.md) · [本阶段目录](README.md) · [全部实验](../README.md)

**前置能力**：[A03 确定性文本处理](../01-basics/A03.md)。

**准备**：一个已跑通的图像模型模板及其配套 MODEL/CLIP/VAE；不用 H3 代替 SD 模型。

**操作与变量**：识别整包 checkpoint 与分开加载的三种对象；相同文本分别编码并在模板内消费；检查 CLIPSetLastLayer 和 T5 选项仅在支持的家族内使用。

**观察与通过标准**：能指出每个加载器的消费者；权重家族、文本编码器和 VAE 三者匹配。不同加载方式仅在同一套实际权重下比较。

**本组逐一验证的节点**：`CLIPSetLastLayer`、`CLIPTextEncode`、`T5TokenizerOptions`、`CheckpointLoaderSimple`、`ImageOnlyCheckpointLoader`、`CheckpointLoader`、`CLIPLoader`、`DualCLIPLoader`、`QuadrupleCLIPLoader`、`TripleCLIPLoader`、`DiffusersLoader`、`UNETLoader`、`VAELoader`。

**初始状态**：待执行。一个节点的成功不能替同组其它节点验收。
