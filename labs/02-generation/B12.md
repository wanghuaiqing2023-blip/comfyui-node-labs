# B12 LoRA 与旁路

[项目首页](../../README.md) · [本阶段目录](README.md) · [全部实验](../README.md)

**前置能力**：[B03 最小文生图与复现](B03.md)。

**准备**：和模型家族匹配的普通风格 LoRA；Turbo LoRA 单独配套测试。

**操作与变量**：比较无 LoRA、强度 0、0.5、1；再测试 model-only 与 model+CLIP 路径。Bypass 调试节点使用前向注入 LoRA 的计算策略，不是关闭 LoRA；比较普通权重合并与前向注入的输出/权重差异，不虚构 bypass 开关。

**观察与通过标准**：强度 0 应接近无 LoRA 基线；记录哪些对象被修改；Turbo 不能仅关 LoRA 而仍沿用 4 步后就判定基础模型失败。

**本组逐一验证的节点**：`LoraLoaderModelOnly`、`LoraLoaderBypass`、`LoraLoaderBypassModelOnly`、`LoraLoader`、`LoraModelLoader`。

**初始状态**：待执行。一个节点的成功不能替同组其它节点验收。
