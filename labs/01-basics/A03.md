# A03 确定性文本处理

[项目首页](../../README.md) · [本阶段目录](README.md) · [全部实验](../README.md)

**前置能力**：[A02 把参数变成数据](A02.md)。

**准备**：无需模型；固定字符串含空格、大小写、数字和换行；另备小 JSON。

**操作与变量**：逐个执行拼接、前后缀、大小写、替换、截取、长度、正则和 JSON 提取，每个结果先 PreviewAny，再保存；TextOverlay 叠加到 A01 图像；专用提示词构造器只测试 JSON 字段组织。

**观察与通过标准**：每个节点都有手算预期；无匹配、空串、多个匹配各做一次。生成文本模型节点另走 E 分支。

**本组逐一验证的节点**：`AddTextPrefix`、`AddTextSuffix`、`BuildJsonPromptIdeogram`、`StringCompare`、`StringConcatenate`、`StringContains`、`ConvertArrayToString`、`ConvertDictionaryToString`、`CaseConverter`、`TextToLowercase`、`TextToUppercase`、`TextOverlay`、`RegexExtract`、`JsonExtractString`、`StringFormat`、`RegexMatch`、`MergeTextLists`、`StringReplace`、`ReplaceText`、`RegexReplace`、`SaveText`、`StripWhitespace`、`StringSubstring`、`StringLength`、`StringTrim`、`TruncateText`。

**初始状态**：待执行。一个节点的成功不能替同组其它节点验收。

BuildJsonPromptIdeogram 子实验先完成 [A10](A10.md)，将 CreateBoundingBoxes.elements 接入 element。
