# A01 建立观察与保存出口

[项目首页](../../README.md) · [本阶段目录](README.md) · [全部实验](../README.md)

**前置能力**：无。

**准备**：无需模型；准备一张带文字与四色角标的 512×384 PNG。

**操作与变量**：LoadImage 的 IMAGE 分别接 PreviewImage、SaveImage、GetImageSize；尺寸三个输出接 PreviewAny。保存后重新加载，与原图送入 ImageCompare。

**观察与通过标准**：能看到原图、尺寸 512×384、batch_size=1；PNG 回读的像素表现一致。不要把 GetImageSize 当图像直通节点：索引仅列三个 INT 输出。

**本组逐一验证的节点**：`ImageCompare`、`GetImageSize`、`LoadImage`、`LoadImageOutput`、`PreviewImage`、`SaveImage`、`PreviewAny`。

**初始状态**：待执行。一个节点的成功不能替同组其它节点验收。
