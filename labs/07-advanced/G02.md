# G02 Hook 的时间控制与组合

[项目首页](../../README.md) · [本阶段目录](README.md) · [全部实验](../README.md)

**前置能力**：[B11 条件组合 区域与时段](../02-generation/B11.md)、[B12 LoRA 与旁路](../02-generation/B12.md)。

**准备**：普通 LoRA 基线、可配 hook 的模型和条件流程。

**操作与变量**：先 CreateHookLora→SetClipHooks/条件设置；再用 keyframes 将强度设为前半开后半关；最后 CombineHooks2/4/8 与 pair/single conditioning 分支分别测试。

**观察与通过标准**：Hook 对象有创建、调度、挂载、消费四步；只创建未挂载不算验证；时间段按采样进度解释，不直接当视频第几秒。CreateHookKeyframesFromFloats 的 FLOATS 输入来源未由本索引闭合，须先核对本机类型与实现。

**本组逐一验证的节点**：`SetClipHooks`、`CombineHooks2`、`CombineHooks4`、`CombineHooks8`、`PairConditioningCombine`、`PairConditioningSetDefaultCombine`、`PairConditioningSetProperties`、`PairConditioningSetPropertiesAndCombine`、`ConditioningSetDefaultCombine`、`ConditioningSetProperties`、`ConditioningSetPropertiesAndCombine`、`CreateHookLora`、`CreateHookLoraModelOnly`、`CreateHookModelAsLora`、`CreateHookModelAsLoraModelOnly`、`CreateHookKeyframe`、`CreateHookKeyframesFromFloats`、`CreateHookKeyframesInterpolated`、`SetHookKeyframes`。

**初始状态**：待执行。一个节点的成功不能替同组其它节点验收。

CreateHookKeyframesFromFloats 的 FLOATS 来源仍需核对；见[输入依赖缺口](../../guides/input-gaps.md)。
