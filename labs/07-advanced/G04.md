# G04 性能 缓存与设备

[项目首页](../../README.md) · [本阶段目录](README.md) · [全部实验](../README.md)

**前置能力**：[B07 拆开采样器](../02-generation/B07.md)。

**准备**：稳定基线与可测的显存/耗时；多 GPU 子实验需实际多卡。

**操作与变量**：EasyCache/LazyCache/FluxKVCache/编译/计算 dtype/attention backend 逐个开关；冷启动和预热分开；设备选择分别测试 MODEL/CLIP/VAE；MultiGPU_WorkUnits 按支持模板使用。

**观察与通过标准**：至少一次预热后三次记录中位耗时、峰值显存和输出误差；没硬件记未执行；有缓存命中不等于本轮重算了模型。

**本组逐一验证的节点**：`EasyCache`、`LazyCache`、`ModelComputeDtype`、`MultiGPU_WorkUnits`、`SelectCLIPDevice`、`SelectModelDevice`、`SelectVAEDevice`、`FluxKVCache`、`TorchCompileModel`。

**初始状态**：待执行。一个节点的成功不能替同组其它节点验收。
