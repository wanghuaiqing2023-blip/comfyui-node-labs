**状态：未运行。** 目标：使用注释解释工作流，并区分给人看的说明和传给节点的输入。

## 准备与操作入口

打开 U01 已恢复正常的图片预览工作流。添加内置 Note，放在图像路径旁。记录搜索或菜单里的完整名称，避免混淆 Note、MarkdownNote 和第三方文本输入节点。本组只要求普通 Note；Markdown 渲染不作为通过条件。

## 单变量用例与可观察预期

| 用例 | 操作与变量 | 明确预期 | 观察/通过标准 |
|---|---|---|---|
| U02-01 文本 | 文本从空白改为“实验：读取彩色图片”，再改为“把图片变成黑白” | 注释显示新文字；重新运行后仍是原彩色图片 | 两次文本截图；当前任务成功；输出像素仍与 U00 基准相同 |
| U02-02 内容长度 | 将单行文字改成三行：“输入：测试图”“预期：颜色不变”“实测：待填写” | 文字内容和行数变化，按编辑器显示区域呈现；图像输出不变 | 确认三行均可通过查看/滚动读到；记录自动换行或滚动表现，不要求特定排版 |
| U02-03 位置与尺寸 | 先只移动 Note，再只调整 Note 的宽度（若支持） | 注释位置/文本排版变化，图像路径连线与参数保持不变 | 两步分别截图；输出不变。不支持调整大小时标该操作不可用 |
| U02-04 移除 | 在副本中选中且仅删除 Note，再运行 | 注释消失；LoadImage、重路由和预览仍在，运行和图片结果不受影响 | 删除前后截图与成功任务；之后撤销或从保存副本恢复 Note |

这里“把图片变成黑白”只是一段注释。真正的图像变化需要数据路径中的处理节点；Note 不能替代提示词编码器或 STRING 数据来源。

## 常见偏差与排查

若改 Note 后图片发生变化，核对是否同时修改了加载图片、连线或其他节点。若找不到 Note，记录搜索结果及版本；不要把能输出 STRING 的节点当成等价注释。

## 通关与证据

保存 `U02-note` 工作流及四行用例记录。用 Note 写清输入、唯一变量、预期、实际观察；能回答“注释写一条命令为什么没有执行”。保存与重开是否保留文字在 U04 验证。
