# F07 视频目标跟踪

[项目首页](../../README.md) · [本阶段目录](README.md) · [全部实验](../README.md)

**前置能力**：[F06 目标检测与自动遮罩](F06.md)、[C02 视频时间裁剪与潜空间帧](../03-audio-video/C02.md)。

**准备**：匹配 SAM3 跟踪模型；先单人短视频，再两人交叉但尽量无遮挡的片段。

**操作与变量**：SAM3_VideoTrack 的 images 接帧批次，model 接其专用模型，提供有效 initial_mask 或匹配文本条件；track_data→SAM3_TrackPreview/TrackToMask。

**观察与通过标准**：逐帧确认同一 track 对应同一人；记录 ID 切换和漏检；帧数、mask 与原视频同步。

**本组逐一验证的节点**：`SAM3_VideoTrack`、`SAM3_TrackPreview`、`SAM3_TrackToMask`。

**初始状态**：待执行。一个节点的成功不能替同组其它节点验收。
