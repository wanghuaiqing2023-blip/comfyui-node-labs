# F08 SAM3D 人体姿态预测

[项目首页](../../README.md) · [本阶段目录](README.md) · [全部实验](../README.md)

**前置能力**：[C02 视频时间裁剪与潜空间帧](../03-audio-video/C02.md)、[F06 目标检测与自动遮罩](F06.md)、[F01 三维文件 相机与预览](F01.md)。

**准备**：SAM3DBody_Loader 的匹配人体模型；单人抬手且移动的短视频；多人分支额外先做 F07。

**操作与变量**：GetVideoComponents.images→SAM3DBody_Predict.image，Loader→Predict.sam3d_body_model；输出 MHR_POSE_DATA→SAM3DBody_Render→PreviewImage/CreateVideo；必要时使用对应 bboxes。

**观察与通过标准**：人体关节动作与原视频大致对应；确认帧数与人物范围。SAM3D model 类型和通用 MODEL 不互换；POSE_KEYPOINT 也不能直接当 MHR_POSE_DATA。

**本组逐一验证的节点**：`SAM3DBody_Loader`、`SAM3DBody_Render`、`SAM3DBody_Predict`。

**初始状态**：待执行。一个节点的成功不能替同组其它节点验收。
