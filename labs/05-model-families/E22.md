# E22 SeedVR2 与 SUPIR 修复

[项目首页](../../README.md) · [本阶段目录](README.md) · [全部实验](../README.md)

**前置能力**：[C04 学习型放大与插帧](../03-audio-video/C04.md)、[B04 图生图与去噪强度](../02-generation/B04.md)。

**准备**：两者分别使用配套恢复模型；低分辨率图/短视频。

**操作与变量**：SeedVR2 Preprocess→Conditioning/采样→PostProcessing；TemporalChunk→Merge 核对边界帧；SUPIR 单独比较默认和一个控制强度。

**观察与通过标准**：输出尺寸、细节和时间接缝分别评价；修复生成的细节不等于恢复了真实原始信息。

**本组逐一验证的节点**：`SeedVR2PostProcessing`、`SeedVR2Preprocess`、`SeedVR2Conditioning`、`SeedVR2TemporalMerge`、`SeedVR2TemporalChunk`、`SUPIRApply`。

**初始状态**：待执行。一个节点的成功不能替同组其它节点验收。
