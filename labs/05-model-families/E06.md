# E06 多阶段生成与专项图像处理

[项目首页](../../README.md) · [本阶段目录](README.md) · [全部实验](../README.md)

**前置能力**：[B04 图生图与去噪强度](../02-generation/B04.md)、[B05 局部重绘与外扩](../02-generation/B05.md)、[B07 拆开采样器](../02-generation/B07.md)。

**准备**：Stable Cascade、InstructPix2Pix、Lotus、PiD、SD 4X 分别使用其任务模板。

**操作与变量**：Cascade 先 Stage C→Stage B，再单独变阶段条件；编辑模型改一条指令；Lotus 使用其预期任务输入；4X 对比基础放大；DifferentialDiffusion 比较二值与灰度遮罩。

**观察与通过标准**：每个阶段输出由对应下游消费；不同功能不以画质一个指标衡量；差异扩散依赖正确 mask 流程。

**本组逐一验证的节点**：`DifferentialDiffusion`、`StableCascade_SuperResolutionControlnet`、`PiDConditioning`、`InstructPixToPixConditioning`、`LotusConditioning`、`StableCascade_StageB_Conditioning`、`SD_4XUpscale_Conditioning`、`StableCascade_EmptyLatentImage`、`StableCascade_StageC_VAEEncode`。

**初始状态**：待执行。一个节点的成功不能替同组其它节点验收。
