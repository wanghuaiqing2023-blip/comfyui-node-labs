# E19 TripoSplat 生成

[项目首页](../../README.md) · [本阶段目录](README.md) · [全部实验](../README.md)

**前置能力**：[B07 拆开采样器](../02-generation/B07.md)、[F01 三维文件 相机与预览](../06-vision-3d/F01.md)。

**准备**：TripoSplat 配套权重、输入图片和透明背景预处理。

**操作与变量**：PreprocessImage→Conditioning→采样→VAEDecodeTripoSplat；中间 TripoSplatSamplingPreview 与最终渲染对照，再交 F05。

**观察与通过标准**：生成结果确为 splat 表示；检查背景、坐标、splat 数与渲染轮廓，不能当普通 MESH。

**本组逐一验证的节点**：`TripoSplatConditioning`、`TripoSplatPreprocessImage`、`VAEDecodeTripoSplat`、`TripoSplatSamplingPreview`。

**初始状态**：待执行。一个节点的成功不能替同组其它节点验收。
