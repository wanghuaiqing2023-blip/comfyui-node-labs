# E15 Wan 音频驱动与续接

[项目首页](../../README.md) · [本阶段目录](README.md) · [全部实验](../README.md)

**前置能力**：[E11 Wan 基础与首末帧](E11.md)、[C03 音频通道 时间与封装](../03-audio-video/C03.md)。

**准备**：Dancer、HuMo、InfiniteTalk、Sound 对应模板及音频编码器。

**操作与变量**：先 AudioEncoderLoader→AudioEncoderEncode 或家族指定编码；换一段节奏明显不同的声音；Dancer keyframe padding 检查对齐，Sound extend 检查连接处。

**观察与通过标准**：音频采样率/时长/视频帧数匹配；节奏、口型和续接分别评价；不能仅音轨成功封装就说音频驱动有效。

**本组逐一验证的节点**：`WanDancerPadKeyframes`、`WanDancerPadKeyframesList`、`AudioEncoderEncode`、`WanDancerEncodeAudio`、`WanDancerVideo`、`WanHuMoImageToVideo`、`WanInfiniteTalkToVideo`、`WanSoundImageToVideo`、`WanSoundImageToVideoExtend`、`AudioEncoderLoader`。

**初始状态**：待执行。一个节点的成功不能替同组其它节点验收。
