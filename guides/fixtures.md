# 测试素材清单

[项目首页](../README.md) · [阅读指南](README.md)

| 素材 | 特征 | 用于验证 |
|---|---|---|
| 图片 P1 | 512×384，文字 TOP，四角颜色不同，中间棋盘格 | 尺寸、裁剪、翻转、插值、颜色 |
| 图片 P2 | 透明背景图，有半透明边缘 | alpha、遮罩、合成 |
| 遮罩 M1 | 512×384，中央白矩形，外围黑 | 羽化、扩张、区域控制 |
| 帧序列 V1 | 24 张同尺寸帧，编号 00—23 | 顺序、batch、FPS、时间裁剪 |
| 音频 A1/A2 | 两段不同音调、峰值留余量、时长已知 | 拼接、混合、通道、同步 |
| 人体视频 P3 | 单人抬手并侧移，尽量无遮挡 | 姿态、平滑、根节点平移 |
| 人体视频 P4 | 两个动作不同的人 | tracking、track_index |
| 三维素材 G1 | 已知尺度与朝向的 GLB，另有动画 GLB | 相机、保存回读、动画 |
| 三维素材 G2 | 有已知孔洞/重复顶点的网格，棋盘纹理 | 拓扑、UV、法线与烘焙 |
| Splat S1 | 已验证可读的 Gaussian splat 文件 | splat 属性、转换与渲染 |

这些是素材要求，不表示本次已生成或附带了这些素材。除已知坐标/编号等确定性图案外，优先用现有文件减少准备成本。
