# 实验记录模板

[项目首页](../README.md) · [阅读指南](README.md)

每个节点的每一项 A/B 比较都复制一行。单元实验编号建议用 [A08](../labs/01-basics/A08.md)-ImageCompositeMasked-01 这样的可读编号。

| 字段 | 要填写的内容 |
|---|---|
| 实验组与节点 | 例如 [A08](../labs/01-basics/A08.md) / ImageCompositeMasked |
| 软件和资源 | ComfyUI 版本/提交、前端版本、模型名/校验值、设备与计算精度 |
| 前置检查 | 输入类型、形状、模型家族、单位、时间轴是否已确认 |
| 基线 A | 工作流文件、输入文件、所有关键参数、seed |
| 变体 B | 唯一改变的节点或参数 |
| 运行前预测 | 应变化的量与应保持的量 |
| 实测证据 | 图像/音频/视频/GLB 文件、尺寸、帧数、时间、相关日志 |
| 判断 | 通过、失败、缺资源或待核对文档 |
| 下一步 | 最小复现实验或已定位的问题 |
| 迁移练习 | 换素材后能否独立完成与解释 |

### 量化观察的最低要求

- 图像：宽、高、batch、通道与角标位置；确定性变换可比较像素差，生成任务不能只看单个像素差。
- 遮罩：尺寸、取值范围、白色区域与下游作用方向；灰阶不是二值错误。
- 潜空间：家族、形状、批次/时间含义；必要时用只读调试查看元数据，不把巨量 tensor 当可读教学内容。
- 视频：有效帧数、FPS、首末帧编号、播放时长；区分抽帧、改帧率、插帧。
- 音频：采样率、通道、样本数/时长、峰值、同步。
- 三维：表示类型、顶点/面/splat 数、单位、朝向、相机、动画时长。
- 性能：冷启动与预热分开，同一基线、同一输出；速度、显存和结果误差一起看。
- 训练：训练与验证素材分开；功能管线通过后才评估是否值得继续训练。

### 遇到异常的排查顺序

1. 没有输出：检查输出节点、缺少输入、未选分支、缓存及执行日志。
2. 不能连线：检查真实端口类型、联合类型与动态控件，不靠颜色猜。
3. 能连线但运行失败：检查模型家族、数据维度、缺字段、批次与版本。
4. 输出尺寸或时间不对：检查对齐、帧网格、裁剪、编码器时间压缩和 FPS。
5. 参数似乎没用：确认该分支启用、变量被下游消费、测试素材包含足够变化。
6. 输出有差异但难解释：恢复基线，一次只改一个变量；随机质量判断至少三个固定种子。
