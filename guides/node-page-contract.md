# 单节点实验页面与前置依赖标记

[项目首页](../README.md) · [逐节点目录](../nodes/README.md)

## 一节点一主页

固定索引的 639 个后端节点分别在 `nodes/实验组/内部类名.md` 维护唯一主实验页面；页面包含作用、常见使用场景、前置节点、输入与输出、基准、参数对照、可观察预期、记录方法及版本依据。一个节点可以有多个用例，不为每个用例重复创建节点主页。

Reroute、Note 和 Group 分别在 `nodes/frontend/`。Group 是画布分组功能；其页面沿用单节点页面组织方式，但不计为新增后端计算节点。U01—U03 是课程导航入口，U04 是跨功能保存恢复实验。其他实验组页面保留组合实验和学习顺序，节点详情通过链接访问。

## 前置节点如何读

| 标记 | 含义 | 学习与接线方式 |
|---|---|---|
| 必需输入 | 本节点契约要求输入存在 | 选一个满足要求的来源；不要求把所有候选都接上 |
| 可选输入 | 只有相应分支才使用 | 根据要验证的场景决定是否连接；部分模式会产生条件必需性 |
| 接口来源示例 | 固定索引存在对应输出端口 | 用页面链接先学上游，再按数据内容、尺寸、批次检查 |
| 兼容性候选 | 模型/条件/潜变量等存在类型匹配，但语义可能不同 | 必须保持模型家族、权重、编码器、布局与处理阶段匹配，不等于已运行验证 |
| 展开后核对 | 动态端口、列表、模式选择或通配类型 | 展开后检查子端口，候选不能直接作为顶层连线承诺 |
| 前端控件 | 数据来自录音、摄像头、调色板或三维视图等 | 在本节点操作控件，不能为了凑依赖虚构加载器 |
| 来源待核对 | 固定索引没有足够证据确定生产者 | 记录缺口和实际环境，不能自连接或强行用 STRING 替代 |

例如：BuildPoseFile 的 `pose_data` 可以来自 SAM3DBody_Predict，也可以来自 SAM3DBody_Smooth。需要平滑时才选后者；两者不是必须同时输入。`sam3d_body_model` 在顶层标 optional，具体导出模式可能需要它。

TextGenerate 的 `clip` 虽然类型名是 CLIP，实际需要当前实现支持并具备文本生成能力的模型；普通 CLIP 文本编码器不能替代。加载器节点和外部模型权重是两个不同层面的依赖。

## 学习前置与运行前置

学习前置是理解当前节点所需的上游概念；运行前置是一次实际执行必须提供的数据对象。文件加载、常量或编辑器控件可能不依赖上游节点，仍可能依赖文件、权限或模型资源。

页面列的是直接输入来源和对应学习链接。点击上游节点页面可以继续追溯，不在每页重复全部传递依赖。多个节点能相互处理对方的结果，不代表应在同一工作流构造环；也不能把来源候选集合当成已经验证的全局拓扑图。

## 依据、状态与维护

场景按节点用途编写；端口依据项目固定索引。静态接口不能证明模型匹配、批次语义或所有可选分支，因此页面显式保留兼容性候选与输入缺口。这里的“常见场景”是功能适用示例，不是使用频率统计。

后端生成源：`tools/node_context.py` 的逐节点用途、场景特例、输入来源规则和覆盖项；`tools/build_node_labs.py` 负责渲染。结构化结果为 `data/node-context.json`。修改生成源后运行生成器和校验器，不能只改生成页面。

结构检查覆盖场景完整性、直接来源节点与输出端口存在性、类型交集及相对链接；它不证明工作流在 RunningHub 已运行，也不证明相同端口类型就兼容。实际证据使用原实验记录模板另存。
